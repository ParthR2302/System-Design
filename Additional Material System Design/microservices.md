Microservices are:

An architectural style where an application is broken into independently deployable services, each owning a specific business capability and communicating over the network.

Problems with Monolithic
- Huge Codebase
- One bug can kill everything
- Scaling enefficiency
- Technology Lock-in


| Monolith         | Microservices        |
| ---------------- | -------------------- |
| One app          | Many services        |
| One deploy       | Independent deploy   |
| Easy local calls | Network calls        |
| Simple initially | Complex initially    |
| Hard scaling     | Fine-grained scaling |
| Tight coupling   | Loose coupling       |
