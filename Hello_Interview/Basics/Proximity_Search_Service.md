# Proximity Service

Proximity search is a powerful feature in search engines, databases, and geospatial applications that enables users to find results based on the closeness of keywords or locations. This advanced search mechanism can significantly enhance user experience by delivering highly relevant and contextual results.

It has two main categories:
1. **Keyword Proximity Search:** Finds occurrences where specified keywords appear close together within textual content.
2. **Geographical Proximity Search:** Finds locations or objects within a specific physical distance from a reference point.
